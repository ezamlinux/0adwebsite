# 0adwebsite

A fan website for [0 A.D.](https://play0ad.com)

built with [Hugo](https://gohugo.io).

## Requirements

- [Hugo](https://gohugo.io/installation/) (extended edition)

## Getting started

```sh
git clone git@github.com:Jeff-web-sketch/0adwebsite.git
cd 0adwebsite
hugo server -D
```

Then open <http://localhost:1313>.

## Building

```sh
hugo --minify
```
